Historical football datasets

These files support articles published in 2015. They are historical snapshots, not live feeds. Original attribution is preserved below; the original collection and transformation scripts are incomplete.

  • Arsenal league results: September 1893–May 2015 (season labels 1893–2014), attributed in the original article to engsoccerdata. ArsenalWin: 0 = Arsenal win, 1 = draw, 2 = Arsenal loss. Goals and results are from the home team's perspective; venue identifies Arsenal's side.
  • European league standings: November 2015 snapshot used by the November 13 article. Original attribution: WhoScored. P = matches played; Pts = points; PPG = points / matches played; CNTRY = country. Exact collection time is not recorded.
  • Premier League rank transitions: 2000–01 through 2014–15, standings after 12 matches versus final standings. Original attribution: WhoScored. start and end are ranks, 1 = highest. Transitions in rankchangedn.csv and transitions in rankchangeup.csv aggregate counts; despite its filename, the published chart uses rankchangedn.csv for upward mobility (a smaller final rank is better).
  • Rank-class transition table: percentages between five groups of four ranks, from top four (Elites) to bottom four (No-hopers).
  • Arsenal player radar metrics: through December 15, 2015; original attribution: WhoScored. Values are normalized relative to team leaders, on a 0–1 scale. Position metadata determines chart groups; goalkeepers are excluded from outfield charts. The accessible table retains every source record.

The original analysis notebooks are retained for reference. Their Python environment and input paths have not been reconstructed. No new data collection or model results were introduced during maintenance.

Dataset licensing is not established by this repository. Consult the original providers before redistribution. When adding seasons, retain these snapshots and record the new source, collection date, units, and transformations separately.
